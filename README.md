# HR Analytics Dashboard

## 📊 Project Overview

This project is an interactive **HR Analytics Dashboard** built using **Power BI and Excel**. It analyzes employee data to provide insights into workforce distribution, salary, attendance, performance, experience, gender, and employee attrition.

## 🛠️ Tools & Technologies

* Power BI
* Microsoft Excel
* DAX
* Data Visualization
* Data Analysis

## 📌 Key Features

* 600 employee records analyzed
* 8+ KPI metrics
* Department-wise employee analysis
* Gender distribution
* Average salary analysis
* Performance rating analysis
* Attendance analysis
* Employee attrition analysis
* Experience distribution
* Interactive filters for Department, Gender, Job Role, and Attrition

## 📈 Dashboard Insights

The dashboard provides an interactive view of employee workforce data and helps analyze different HR-related metrics through KPI cards, charts, and filters.

## 📁 Files

* `HR_Analytics_Dashboard.pbix` – Power BI dashboard
* `HR_Analytics_Employee_Data.xlsx` – Employee dataset
* `HR_Analytics_Dashboard.png` – Dashboard preview

## 🎯 Objective

To create an interactive HR dashboard that helps understand employee workforce patterns and supports data-driven HR reporting.
